Command Reference

grep

Search for patterns in text

grep "pattern"
grep -i "pattern" (case-insensitive)
grep -v "pattern" (invert match)
grep -c "pattern" (count matches)
grep -n "pattern" (show line numbers)
grep -w "word" (whole word only)
grep -E "a|b" (extended regex OR)
grep 'a\|b' (same in basic regex)
grep '[[:digit:]]' (POSIX class; \d needs -P)
grep -x "line" / grep -F "a.b" (whole line / no regex)
grep "^start" / grep "end$" (anchors)

head / tail

Show first/last lines

head -n 5 or head -5
tail -n 3 or tail -3
tail -n +2 (from line 2, e.g. skip header)

wc

Count lines, words, characters

wc (all counts)
wc -l (lines only)
wc -w (words only)
wc -c (bytes, including newlines)

sort

Sort lines alphabetically/numerically

sort (byte order, like LC_ALL=C: A-Z before a-z)
sort -n (numeric)
sort -r (reverse)
sort -u (unique only)
sort -f (ignore case)
sort -t',' -k2,2 (by field 2 only, comma-delimited)
sort -k3n (numeric key: field 3 to end of line)

uniq

Filter duplicate adjacent lines

uniq (remove duplicates)
uniq -c (count occurrences)
uniq -d (show duplicates only)
uniq -u (show unique only)
uniq -i (ignore case)

cut

Extract columns/fields from text

cut -c1-5 (characters 1-5)
cut -d',' -f2 (field 2, comma-delimited)
cut -d':' -f1,3 (fields 1 and 3)
cut -d',' -f2- (field 2 to the end)

tr

Translate or delete characters

tr 'a-z' 'A-Z' (to uppercase)
tr '[:lower:]' '[:upper:]' (char classes)
tr -d '0-9' (delete digits)
tr -s ' ' (squeeze spaces)

cat

Display or concatenate text

cat (pass through)
cat -n (number lines)

rev

Reverse each line

rev

tac

Reverse line order

tac

sed

Stream editor

sed 's/old/new/' (first match)
sed 's/old/new/g' (all matches)
sed 's|/a|/b|' (any delimiter)
sed 's/cat/[&]/' (& = the match)
sed -E 's/(a+) (b+)/\2 \1/' (groups)
sed 's/\(a*\) \(b*\)/\2 \1/' (groups without -E)
sed '2,4s/a/b/' (only on lines 2-4)
sed -n '1p;$p' (several commands)
sed '/pattern/d' (delete matching)
sed '2d', sed '2,4d' (delete lines)
sed -n '2,4p' (print only lines 2-4)

awk

Field-based processing

awk '{print $1}' (1st field)
awk -F',' '{print $2}' (custom separator)
awk '{print $NF}' (last field)
awk '{print NR": "$0}' (line numbers)
awk '$3 > 100' (filter by condition)
awk '$2 == "x" {print $1}' (match + print)
awk '{s += $1} END {print s}' (sum)

nl

Number lines

nl (number non-empty lines)

paste

Merge lines

paste -sd',' (join all lines with ,)
paste -s -d'+' (join with +)

Pipes

Chain commands together

cmd1 | cmd2 | cmd3
Example: sort | uniq -c | sort -rn

Files & the shell

Tasks with files list them in the Input panel

grep ERROR app.log (file argument)
wc -l *.log (wildcards: * ? [ab])
sort a.txt > out.txt (write a file)
grep x f >> log.txt (append)
tr a-z A-Z < f.txt (file as stdin)
cmd 2>/dev/null (hide errors), 2>&1
a; b (one after another)
a && b / a || b (if a succeeded / failed)
echo $? (exit status of the last command)

awk — the language

Arrays, conditions, loops, printf, functions

awk '{c[$1]++} END {for (k in c) print k, c[k]}'
awk '{s[$1] += $2} END {...}' (sum per key)
awk '!seen[$0]++' (unique, keep order)
awk '{printf "%-10s %5.2f\n", $1, $2}'
awk '{if ($2 > 5) print "big"; else print "small"}'
awk -v n=3 'NR <= n' (variables)
length() substr() index() split()
sub() gsub() match() toupper() tolower()
awk '/start/,/end/' (range pattern)

grep — more

Context and files

grep -A2 x / -B2 / -C2 (lines after / before / around)
grep -l x *.log (names of matching files)
grep -r x dir (all files below dir)
grep -h / -H (hide / show file names)
grep -q x f && echo yes (only the exit status)

sort — more

Human sizes, versions, output file

sort -h (2K < 1M < 3G)
sort -V (v1.9 < v1.10)
sort -o out.txt (write the result to a file)
sort -c (check if sorted)

sed — more

Editing files and other commands

sed -i 's/a/b/' file (edit in place, -i.bak keeps a backup)
sed 'y/abc/xyz/' (translate characters)
sed '1i text' / '$a text' (insert / append a line)
sed '2,4c text' (replace lines)
sed -n '/x/w out.txt' (write matching lines to a file)

echo / printf / seq

Produce text

echo hello, echo -e 'a\tb'
printf '%s=%d\n' a 1 b 2
seq 5, seq 2 2 10, seq -s, 5, seq -w 10

fold / column

Layout

fold -w 20 (wrap lines), fold -s -w 20 (at spaces)
column -t (align a table), column -t -s,

comm / join / paste

Combine files

comm -12 a b (lines in both sorted files)
comm -23 a b (only in a)
join a b (match lines on the 1st field)
paste -d, a b (side by side)

ls / tee

Files and copies of output

ls, ls logs, ls *.log, ls -F
sort f | tee out.txt | head -3 (save and pass on)
